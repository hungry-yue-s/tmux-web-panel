## 统一设计方案

方向：安静、可读的原生工作台。终端和预览承担内容，导航与操作形成稳定辅助层。继续支持现有 12 主题，界面文字用独立语义映射，终端保留用户的字体和颜色设置。

```text
┌ 系统按钮 / 工作区导航 ┬ 机器 › 会话 › 窗口   布局 字号 文件 更多 ┬ 文件标签 ┐
│ 本机          在线   │                                       │          │
│ 会话                 │                 终端                  │ 文档预览 │
│   工作区             │                                       │          │
│   API 服务           │                                       │          │
│ 终端  状态  设置     │                                       │          │
└──────────────────────┴───────────────────────────────────────┴──────────┘
```

- 导航：248px 可调侧栏，紧凑态保持窗口名称。扁平会话分组、清晰缩进；选中项同时有底色和边线。
- 顶栏：Swift 系统按钮保留 80px 安全区；44px 内容基线；面包屑左对齐，布局、字号分组，低频动作放入更多。
- 文件：保留 modal-first、显式 dock、每个标签的独立状态；隐藏保留标签，关闭只销毁指定标签。正文控制阅读宽度，表格在预览内部横滚。
- 状态：单一机器标题；指标、告警、采样时间分层；未知值保留破折号。Agent 的额度、消耗、当前身份与供应商详情分层，不混算。
- 设置：紧凑主题预览；透明度、毛玻璃放进同一设置区，有数值和实时示例；浏览器不出现不能生效的 native 控件。
- 移动：保留工作区菜单、pane 条与 FAB 抽屉；44px 触摸目标，软键盘与抽屉互斥，考虑安全区。
- 可访问性：普通文字 4.5:1，关键非文字控件 3:1；可见焦点、语义选中状态、键盘调宽；尊重 reduced-motion。

设计约束详见 [design-system.md](../.superdesign/design-system.md)。

## 技能应用与自检

UI/UX Pro Max：检索产品级方向、文字对比度和图标语义。产品检索混入营销页 Hero/CTA 结构，已舍弃；采用功能层级、扁平工具界面和可访问性建议。

Frontend Design：先整理色彩、字体和布局约束，再检查是否落入营销模板；选择连续的终端与文件工作区，不添加装饰图、渐变卡片或远程字体。

Superdesign：初始化源码上下文、提取共享导航、复现演示基线，再进行受约束重设计，保留画布和恢复上下文。Ponytail：复用既有 DOM、Theme、SVG 和原生材质，不引入框架或组件库。Ego-browser 与 CUA：分别验证隔离网页和独立 Swift 实例。

## 视觉精修：石墨材质工作台

用户反馈 v3 简陋、缺乏高级感，本轮保留熟悉的信息架构，重新处理材质、排版和控件细节：

- 终端采用更深的石墨表面；文档使用较浅表面、12px 留白、柔和边缘与阴影。侧栏在独立 Swift 客户端中透出轻微原生材质，浏览器保持不透明。
- 布局及字号操作采用嵌入式分组；低频操作收进更多菜单。机器信息、会话层级、选中行和命令元信息有明确权重。
- 文档改为有段落、检查摘要和待办的中文项目笔记；主题缩略图增加微型窗口结构及选中标记，滑块数值采用等宽数字。
- 删除生成稿里的英文设计说明、缺字图标和未实现的编辑/保存操作，恢复现有产品范围内的复制、下载；修复字号按钮失效。

本轮使用 UI/UX Pro Max 的材质与对比度建议、Frontend Design 的视觉自检、Superdesign 的单方向迭代，以及 Ponytail 的既有结构复用。v4 由 Claude Sonnet 5 生成，v5 完成内容和交互修正；没有新增比较变体或生产依赖。

验证：四种宽度的 12 个页面布局无整页横向溢出；隐藏/恢复保留同一预览 DOM；键盘调宽最大 820px；透明度与毛玻璃示例独立；浏览器实测字号 14→15px；移动导航 44px；独立 Swift 实际截图检查通过。脚本初始化、导航、字号与浅色主题还通过了可执行的 DOM 冒烟检查。终端里的测试输出是演示内容，不作为这些验证的证据。

## 侧栏与面板间距修正（v6）

根据用户反馈，将侧栏恢复为接近正式版的紧凑会话分组：移除树形装饰线和额外缩进，机器切换器使用在线圆点与简洁连接信息。恢复 248px 展开 / 152px 折叠按钮，紧凑态保留窗口名称；状态仅保存到原型专用 localStorage 键，不读取正式应用设置。

终端与文档组成连续工作面，外侧保留 12px 留白，中间由原来的两份 gap 收紧为实测 1px 分隔线。拖动命中区域 12px 向两边覆盖，不占用内容宽度；保留键盘调宽、隐藏与恢复。

验证：375/768/1280/2560px × 深浅主题 × 展开/折叠 × 终端/状态/设置，共 48 个布局无整页横向溢出；桌面分隔线实测 1px，拖动区域 12px。折叠后保留选中窗口，会话展开/收起、预览隐藏/恢复保留 DOM、移动菜单开关、刷新后保存折叠状态均通过。实际指针拖动预览宽度 420→460px，aria 数值同步。DOM 脚本初始化与按钮结构检查通过；独立 Swift 客户端实际加载及截图检查通过，系统按钮安全区保留。

本轮只更新设计原型并刷新独立 Review 客户端，正式应用及服务没有重启。
