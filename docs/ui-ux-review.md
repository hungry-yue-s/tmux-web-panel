# 全局 UI/UX 审查与重设计

日期：2026-10-21。基线：`3eb853c`。范围：Swift 主窗口、浏览器工作台、终端侧栏、文件预览、性能、Agent 控制台、连接和设置。

## 当前真实应用：单层工作台

最新配色整理及旧主题修正见 [配色方案](design/theme-palettes.md)。

当前分支 `design/workspace-v2`，隔离入口为 [工作台](http://127.0.0.1:17681/)。本轮重构直接作用于真实 AppShell、MsApp、xterm 和文件预览；独立 Swift Review 也已刷新。下文的原型与早期审查保留为历史，画布 v9 不代表这一轮的真实代码。

设计参考来自 [Linear 2026 界面调整](https://linear.app/now/behind-the-latest-design-refresh)、[Figma UI3 复盘](https://www.figma.com/blog/our-approach-to-designing-ui3/)、[Vercel Geist](https://vercel.com/geist/introduction) 和 [Supabase Design System](https://supabase.com/design-system)。借鉴内容优先、稳定导航和动作层级；本项目以深海表面、暖铜选中态及连续工作面建立自己的视觉。

- **导航只保留一套。** 44px 功能列与会话目录组成侧栏；当前会话加大文字，当前窗口使用实色暖铜底。保留 248px 展开、152px 紧凑态、拖动调宽和原有稳定 ID 路由。低频服务器切换放在侧栏底部。
- **顶栏只有一层。** 网页 48px、Swift 44px，机器／会话／窗口横向排列。删除独立窗口条和窗格条；窗口在侧栏切换，多窗格用紧凑选择菜单。模式、分屏、文件保留直接入口，刷新、字号、标签、弹窗和全屏进入更多菜单。移动端继续使用原 pane 条与 FAB，保留 IME、复制和软键盘契约。
- **终端与文件组成连续工作面。** 单行 Grid 占满顶栏以下全部高度，无外框、间隙或额外导航行。预览默认 360px、限定 320–820px，同时为终端保留至少 60% 和 480px；不足时使用 modal。隐藏预览保留标签，恢复按钮悬浮在右缘，不占列。桌面字号仍固定从 14px 开始，不随旧 tmux 网格缩小。
- **文件操作按频率分层。** 工具栏常驻刷新、分栏／隐藏、更多、关闭四个入口。最大化、另开标签、两种复制、分享和两种下载集中在一个菜单，保留原动作监听与状态；支持方向键、Home／End、Escape 和焦点恢复。文件标签显示名称，工具栏显示目录，完整路径留在提示中。
- **状态页与设置使用同一套语义色和层级。** 状态页合并重复操作；本机连接展示本地进程、平台、架构、主机与实测能力，不显示虚构 SSH 握手。远端仅在有检测结果时显示验证通过。主题预览使用实际工作区颜色；13 个主题的 ANSI 调色板保持原样。
- **原生材质继续使用真实桥接。** 顶栏与侧栏透出原生背景，不写死透明度或 CSS 模糊强度；透明度与毛玻璃分别控制，沿用可见数值和实时更新。Swift 系统按钮安全区保留。

实测 1200×1190px、侧栏 248px 时，主区宽 952px，文件栏 380px，终端宽 572px；删除两层导航后，终端区域从上一版 1054px 增至 **1142px 高**。隐藏预览后终端恢复全部 952px 宽。真实操作已验证窗格切换、A±（14→15→14，菜单保持打开）、文件最大化／恢复；375／768／1280／2560px 无页面横向溢出。CDP 改变 DPR 后会短暂出现画布缩放伪影，固定设备 DPR 并等待渲染后复核，375／768px 的实际终端文字尺寸正常。

最终回归：`TMUX_AGENT_INTEGRATION=0 npm test -- --maxWorkers=1`，95 个测试文件通过、1 个跳过，**1485 项通过、1 项跳过**。首轮有一条未修改的 pane-label API 用例偶发返回 401，单独复测与最终完整复核均通过，未修改该 API 或放宽断言。JavaScript 语法与 diff whitespace 检查通过。复审补齐了当前 pane 无操作选择的焦点恢复、停用／失败服务器的历史能力值处理、目录标题以及分享弹窗的初始焦点、Tab 循环和关闭清理；分享验收只读取已有记录，没有创建真实分享链接。浏览器实际验证：快捷切换覆盖分享层时，第一次 Escape 返回分享，第二次只关闭分享并回到文件更多按钮，dock 保留。Swift 中透明度保持 15%，毛玻璃从 70% 实调到 50% 后恢复 70%，两项数值独立。

正式 Node／tmux／Swift PID 69377／1363／85656 保持运行，正式工作树仍为 `design/deep-current-workspace` 且干净。调试只刷新独立静态页面和 Review 客户端；网页与原生使用不同的合成 tmux 会话，避免 `attach-session -d` 互相脱离。没有修改 tmux C 源码、没有引入新依赖、没有切换正式服务分支。

## 统一设计方案

方向：安静、可读的原生工作台。终端和预览承担内容，导航与操作形成稳定辅助层。继续支持现有 12 主题，界面文字用独立语义映射，终端保留用户的字体和颜色设置。

```text
┌ 系统按钮 / 工作区导航 ┬ 机器 › 会话 › 窗口   布局 字号 文件 更多 ┬ 文件标签 ┐
│ 本机          在线   │                                       │          │
│ 会话                 │                 终端                  │ 文档预览 │
│   工作区             │                                       │          │
│   API 服务           │                                       │          │
│ 终端  状态  设置     │                                       │          │
└──────────────────────┴───────────────────────────────────────┴──────────┘
```

- 导航：248px 可调侧栏，紧凑态保持窗口名称。扁平会话分组、清晰缩进；选中项同时有底色和边线。
- 顶栏：Swift 系统按钮保留 80px 安全区；44px 内容基线；面包屑左对齐，布局、字号分组，低频动作放入更多。
- 文件：保留 modal-first、显式 dock、每个标签的独立状态；隐藏保留标签，关闭只销毁指定标签。正文控制阅读宽度，表格在预览内部横滚。
- 状态：单一机器标题；指标、告警、采样时间分层；未知值保留破折号。Agent 的额度、消耗、当前身份与供应商详情分层，不混算。
- 设置：紧凑主题预览；透明度、毛玻璃放进同一设置区，有数值和实时示例；浏览器不出现不能生效的 native 控件。
- 移动：保留工作区菜单、pane 条与 FAB 抽屉；44px 触摸目标，软键盘与抽屉互斥，考虑安全区。
- 可访问性：普通文字 4.5:1，关键非文字控件 3:1；可见焦点、语义选中状态、键盘调宽；尊重 reduced-motion。

设计约束详见 [design-system.md](../.superdesign/design-system.md)。

## 侧栏与面板间距修正（v6）

## Deep Current：整体结构重设计

用户明确选择“更大胆、有鲜明个性的视觉风格”，并授权团队模式、开源复用和独立新分支。本轮分支为 `design/deep-current-workspace`，不合入或替换正式界面。

重设计的变化落实在结构与工作流程：

- 顶栏提升为整个应用共用的 44px 首行，下方才是导航和工作面；保留真实系统按钮的 80px 安全区。
- 侧栏采用连续深青色材质、短铜色选中标记，取消多层小卡片；保留 248/152px 折叠、窗口名、会话分组与状态保存。
- 工作面取消外围 12px 留白、终端圆角框与双层描边。终端和文档只有 1px 共享分隔线，拖动区域覆盖两边；桌面页脚统一 32px。
