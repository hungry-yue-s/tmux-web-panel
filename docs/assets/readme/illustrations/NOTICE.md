illustrations from that repository.

The Chinese handwriting labels in the two `*-zh.svg` illustrations are stored as SVG paths
derived from [Ma Shan Zheng](https://fonts.google.com/specimen/Ma+Shan+Zheng). Its SIL
Open Font License 1.1 text is kept in `OFL-MaShanZheng.txt`; no font installation is
required to view the README.
